 📊 E-commerce Sales Analysis Dashboard (Power BI)

📌 Project Overview
This project analyzes an e-commerce dataset using Power BI to generate meaningful business insights.  
The dashboard helps understand sales performance, product demand, and customer trends.

 🎯 Objectives
- Analyze total sales and order performance
- Identify top-selling products and categories
- Track sales trends over time
- Understand city-wise sales distribution
- Evaluate customer ratings and product performance

 📂 Dataset
The dataset contains information about:
- Order ID
- Product Category
- City
- Quantity Sold
- Total Amount
- Customer Rating
- Platform

📊 Dashboard Features
The Power BI dashboard includes the following visuals:

- KPI Cards
  - Total Sales
  - Total Orders
  - Total Quantity
  - Average Rating

- Charts & Visualizations
  - Sales Trend Over Time
  - Category-wise Sales
  - Platform-wise Sales
  - Top Selling Products
  - City-wise Sales
  - Category vs Rating Analysis

- Filters / Slicers
  - Category
  - City
  - Platform

🛠 Tools Used
- Power BI
- Excel / CSV Dataset
- Data Visualization Techniques
